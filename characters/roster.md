# 音效包清单（非 TTS，现成音频）

与上方角色清单的区别：**音效包不经过 Fish Audio 合成**，素材为现成音频文件（游戏/系统/梗音效）。制作走同一套 `dialogue.md` + `pack.js` 打包工具链，但：

- `dialogue.md` 的 `text` 字段填音效说明（`pack.js` 要求非空，但不走 `tts.js`，`audio/` 下放现成文件即可）
- 不需要 `reference_id` / 语言 / 口吻锚点，映射的核心是「事件 → 音效」表

状态流转同角色清单：`待调研 → 台词 → 试听 → 身体 → 打包 → 已上传 → 已上线`（音效包默认到 `打包` 为止）。

> 音效包**也要身体段**，没有例外：2.0 的导出要求是"身体 + 8 个可绑事件各至少一条音频"，多一条路径就多一处要跟着改的地方。
>
> 这一条同样是 1.0 时代上传的（当时已传**生产**、待审核）。它**尚未补齐身体**，所以还停在「身体」——`characters/MC音效包/` 下只有 `audio/`，没有 `pet.json` / `spritesheet.webp`，`pack.js` 会以「身体段必需」拒绝。
